# AI助手套件 - 高级文件筛选功能使用指南

## 功能概述

新的高级文件选择器采用紧凑的单行布局设计，为批量处理功能提供了强大而简洁的筛选能力。通过选择筛选类型+输入筛选条件的组合方式，快速精确地选择需要处理的文件。

## 界面布局

### 顶部筛选栏
- **筛选类型选择器**: 下拉菜单选择筛选类型
- **筛选值输入框**: 根据选择的类型输入相应的筛选条件
- **下拉选择器**: 对于文件夹、标签、属性类型，会显示现有值的下拉选择器
- **清除按钮**: 一键清除当前筛选条件
- **快速筛选按钮**: 预设的常用筛选条件，一键应用

## 筛选功能

### 1. 文件夹路径筛选
- **选择**: "文件夹路径"
- **输入方式**: 
  - 手动输入：支持通配符 `*` 和 `?`
  - 下拉选择：从现有文件夹路径中选择
- **示例**: 
  - `Projects/*` - 筛选所有在Projects文件夹下的文件
  - `*/Notes` - 筛选所有在Notes子文件夹中的文件
  - `Test/2024*` - 筛选Test文件夹下以2024开头的子文件夹中的文件

### 2. 标签筛选
- **选择**: "标签"
- **输入方式**: 
  - 手动输入：多个标签用逗号分隔
  - 下拉选择：从现有标签中选择
- **示例**: 
  - `#important` - 筛选包含important标签的文件
  - `#work, #project` - 筛选包含work或project标签的文件

### 3. 属性筛选
- **选择**: "属性"
- **输入方式**: 
  - 手动输入：`属性名=值` 或 `属性名:值`，多个条件用逗号分隔
  - 下拉选择：从现有属性名中选择
- **示例**: 
  - `status=published` - 筛选status属性为published的文件
  - `author:张三, category:技术` - 筛选作者为张三且分类为技术的文件

### 4. 缺少属性筛选
- **选择**: "缺少属性"
- **输入方式**: 
  - 手动输入：属性名，多个属性用逗号分隔
  - 下拉选择：从现有属性名中选择
- **示例**: 
  - `status` - 筛选没有status属性的文件
  - `date, author` - 筛选同时缺少date和author属性的文件
- **用途**: 查找缺少特定元数据的文件，便于批量补充属性

### 5. 查询语法
- **选择**: "查询语法"
- **输入格式**: 使用类似Obsidian查询的语法
- **支持语法**:
  - `path:文件夹路径` - 按路径筛选
  - `tag:标签名` - 按标签筛选
  - `属性名:值` - 按属性筛选
  - 普通文本 - 在文件名中搜索
- **示例**: 
  - `path:Projects/ tag:#important status:active`
  - `author:张三 category:技术`

### 6. 修改日期筛选
- **选择**: "修改日期"
- **输入格式**: 
  - 单个日期: `2024-01-01`
  - 日期范围: `2024-01-01,2024-12-31`
- **用途**: 筛选特定时间段内修改的文件

### 7. 文件大小筛选
- **选择**: "文件大小"
- **输入格式**: 
  - 最小值: `10` (大于10KB)
  - 范围: `10,100` (10KB到100KB之间)
- **用途**: 筛选特定大小范围的文件

## 使用技巧

### 快速筛选
使用预设的快速筛选按钮可以一键应用常用筛选条件：
- **所有文件**: 显示所有文件（清除筛选）
- **当前文件夹**: 筛选当前活动文件所在文件夹中的文件
- **属性status: ❌**: 筛选status属性值为❌的文件
- **缺少status属性**: 筛选没有status属性的文件
- **缺少tags属性**: 筛选没有tags属性的文件

### 实时筛选
选择筛选类型并输入条件后，文件列表会实时更新，无需点击按钮。

### 批量选择
- 使用"全选当前结果"按钮选择所有筛选出的文件
- 使用文件夹级别的复选框选择整个文件夹的文件
- 使用"取消全选"清除所有选择

### 清除筛选
点击"清除"按钮可以重置当前筛选条件，或使用"所有文件"快速筛选按钮。

## 界面说明

### 顶部筛选栏
- **筛选类型选择器**: 选择要使用的筛选类型
- **筛选值输入框**: 根据选择的类型输入相应的筛选条件
- **清除按钮**: 清除当前筛选条件
- **快速筛选按钮**: 预设的常用筛选条件

### 文件列表区域
- **统计信息**: 显示当前筛选结果的文件数量和已选择数量
- **操作按钮**: 全选/取消全选当前结果
- **文件列表**: 按文件夹分组显示，每个文件夹可以单独全选
- **文件信息**: 显示文件名、大小和修改日期

### 底部操作栏
- **选择统计**: 显示已选择的文件数量
- **确认选择**: 确认当前选择并开始批量处理
- **取消**: 关闭选择器

## 注意事项

1. 筛选条件区分大小写
2. 通配符只支持 `*`（匹配任意字符）和 `?`（匹配单个字符）
3. 日期格式使用系统默认格式
4. 文件大小以KB为单位
5. 查询语法解析错误不会影响其他筛选条件

## 性能优化

- 大量文件时建议先使用文件夹筛选缩小范围
- 避免使用过于宽泛的通配符模式
- 可以结合多个筛选条件提高精确度
