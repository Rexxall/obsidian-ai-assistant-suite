# 增强版批量文件选择功能

## 功能概述

全新设计的批量文件选择界面，优先推荐当前文件所在文件夹的文件，并支持手动浏览其他文件夹进行文件选择，提供更智能、更便捷的批量处理体验。

## 功能特性

### 🎯 **智能文件推荐**
- **当前文件夹优先**：自动显示当前文件所在文件夹的其他Markdown文件
- **排除当前文件**：避免对正在编辑的文件进行批量处理
- **文件夹感知**：基于文件组织结构提供相关文件建议

### 📁 **灵活文件夹浏览**
- **文件夹列表**：显示所有包含Markdown文件的文件夹
- **文件计数**：每个文件夹显示包含的文件数量
- **深度浏览**：点击文件夹查看其中的具体文件
- **快速返回**：一键返回文件夹列表视图

### 🎨 **优化的用户界面**
- **标签页设计**：清晰分离当前文件夹和浏览功能
- **实时计数**：显示已选择的文件数量
- **批量操作**：支持全选当前文件夹或特定文件夹
- **响应式布局**：适配不同屏幕尺寸

## 使用流程

### 1. 启动批量处理
- 通过命令面板或侧边栏启动批量处理
- 选择"选择多个文件"选项

### 2. 当前文件夹选择
- **默认显示**：当前文件所在文件夹的其他文件
- **快速选择**：勾选需要处理的文件
- **批量操作**：使用"全选当前文件夹"快速选择所有文件

### 3. 浏览其他文件夹
- **切换标签**：点击"浏览其他文件夹"标签
- **选择文件夹**：从文件夹列表中选择目标文件夹
- **查看文件**：点击文件夹查看其中的具体文件
- **选择文件**：勾选需要处理的文件

### 4. 确认处理
- **查看计数**：底部显示已选择的文件数量
- **开始处理**：点击"开始批量处理"按钮
- **取消操作**：随时可以取消选择
