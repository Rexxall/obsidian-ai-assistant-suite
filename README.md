## ✨ 核心功能概览

**AI Assistant Suite** 是一个强大的Obsidian插件，提供四大核心AI处理模块，帮助你智能化管理和优化笔记内容。

### 🎯 四大AI智能处理模块

#### 📝 AI Structurizer (结构优化器)
- **智能重排与格式化**：优化笔记的逻辑结构和可读性
- **保留原始措辞**：不重写内容，只重新组织和格式化
- **链接保护**：完美处理Obsidian链接和嵌入内容
- **Markdown增强**：自动添加标题、列表、粗体等格式

#### 🏷️ AI Tagger (智能标签)
- **层级标签系统**：生成符合你现有标签体系的层级标签
- **智能翻译**：自动翻译长英文标签为中文
- **上下文感知**：基于笔记内容智能推荐相关标签
- **批量标签管理**：支持选择性添加多个标签

#### 📁 AI Mover (智能移动)
- **文件夹智能推荐**：基于内容分析推荐最佳存放位置
- **自动创建文件夹**：可以创建新的文件夹结构
- **现有结构感知**：优先使用现有文件夹，保持组织一致性
- **多选项建议**：提供多个移动选项供选择
- **✨ 自定义位置选择**：除AI建议外，可手动浏览选择任意文件夹

#### 📋 AI Meta (元数据生成)
- **智能标题生成**：创建简洁有力的文件标题
- **自动摘要**：生成2-3句话的内容摘要
- **一句话总结**：提供25字以内的核心要点
- **文件重命名**：可选择是否根据生成的标题重命名文件
- **✨ 可编辑元数据**：在侧边栏直接编辑AI生成的标题、摘要和总结
- **🔍 智能字段检测**：自动检测已有的summary/tldr字段，避免重复生成

### 🚀 一键智能处理
- **组合式处理**：一次性执行多个AI模块
- **可配置流程**：自由选择启用的处理步骤
- **智能优化顺序**：先结构优化，再进行其他处理
- **快捷键支持**：`Cmd/Ctrl + Shift + A` 快速启动

### 📦 批量处理系统
- **文件批量处理**：选择多个文件进行批量AI处理
- **文件夹批量处理**：对整个文件夹进行批量处理
- **进度监控**：实时显示处理进度和状态
- **中断恢复**：支持随时中断和恢复处理

### ⚡ 快速操作系统
- **右键菜单集成**：选中文本后右键快速处理
- **四大快速操作**：
  - 📝 总结 (Ctrl+1) - 对选中内容进行简洁总结
  - ✨ 优化 (Ctrl+2) - 优化文本表达方式
  - 🌐 翻译 (Ctrl+3) - 中英文互译
  - 💡 解释 (Ctrl+4) - 详细解释内容含义
- **结果管理**：支持复制结果或直接插入编辑器

### 🎨 智能用户界面
- **AI助手面板**：统一的操作和结果展示界面
- **实时状态监控**：显示API状态、模型信息
- **处理历史记录**：查看最近的AI处理历史
- **使用统计**：统计各功能使用频率
- **文件信息展示**：显示当前文件的字数、字符数等信息

## ✨ 可编辑元数据功能详解

### 功能概述
当AI生成元数据建议时，你现在可以直接在侧边栏中编辑这些内容，无需接受AI的原始建议。这让你能够：
- 🎯 **精确控制**：根据个人需求调整AI生成的内容
- ⚡ **快速修改**：无需重新运行AI，直接编辑即可
- 🔄 **实时更新**：编辑内容会实时反映在文件重命名预览中

### 可编辑字段

#### 📝 标题字段
- **用途**：用于文件重命名和frontmatter中的title字段
- **特性**：
  - 实时字符计数和长度限制
  - 自动过滤非法文件名字符
  - 重命名预览功能
- **编辑方式**：单行文本输入框

#### 📄 摘要字段
- **用途**：添加到frontmatter中的summary字段
- **特性**：
  - 支持多行编辑
  - 自动调整高度
  - 保留换行格式
- **编辑方式**：可调整大小的文本区域

#### 💡 一句话总结
- **用途**：添加到frontmatter中的tldr字段
- **特性**：
  - 建议25字以内
  - 简洁明了的核心要点
  - 快速理解笔记内容
- **编辑方式**：单行文本输入框

### 使用流程

1. **生成AI建议**
   ```
   运行AI Meta或一键处理 → AI生成初始建议
   ```

2. **编辑内容**
   ```
   在侧边栏中直接编辑：
   ┌─────────────────────────────────┐
   │ 标题: [可编辑输入框]             │
   │ 摘要: [可编辑文本区域]           │
   │ 总结: [可编辑输入框]             │
   └─────────────────────────────────┘
   ```

3. **应用修改**
   ```
   [重命名文件] - 使用编辑后的标题重命名
   [仅更新元数据] - 只更新frontmatter，保持文件名
   ```

### 实用技巧

- **标题优化**：根据你的命名规范调整AI生成的标题
- **摘要完善**：添加AI可能遗漏的关键信息
- **总结精炼**：确保一句话总结真正抓住要点
- **批量一致性**：在批量处理时保持命名风格一致

## ✨ 自定义文件夹选择功能

### 功能概述
在AI Mover建议的文件夹选项下方，新增了"选择其他位置"功能，让你可以手动选择任意文件夹作为移动目标。

## � 智能字段检测优化

### 功能概述
AI元数据生成现在能够智能检测文件frontmatter中已有的`summary`和`tldr`字段，避免重复生成，提高效率并保留用户已有的内容。

### 处理策略
- **全部已有**：如果summary和tldr都存在，只生成title
- **部分已有**：如果只有其中一个字段，只生成缺失的字段
- **全部生成**：如果都不存在，正常生成所有字段

### 实际示例

#### 场景1：文件已有摘要
```yaml
---
summary: "这是我手动写的重要摘要"
tags: [笔记]
---
```
**AI行为**：生成title和tldr，保留现有summary

#### 场景2：文件已有完整元数据
```yaml
---
summary: "详细的内容摘要"
tldr: "核心要点总结"
---
```
**AI行为**：只生成title，保留现有summary和tldr

### 优势
- **保护用户内容**：不会覆盖精心编写的元数据
- **提高效率**：减少不必要的AI生成，节省时间和成本
- **智能优化**：根据实际需要调整AI请求内容

## 🔧 故障排除

### 常见问题

**Q: API请求失败怎么办？**
A: 检查API Key和URL配置，确认网络连接正常，查看API服务状态。

**Q: 处理结果不理想？**
A: 可以在设置中自定义提示词，或者调整模型参数。

**Q: 批量处理中断了？**
A: 插件支持中断恢复，可以重新启动批量处理。

**Q: 标签翻译不准确？**
A: 可以在设置中调整翻译提示词或禁用自动翻译。

### 性能优化建议
- **模型选择**：快速操作使用轻量级模型
- **并发控制**：避免同时进行多个AI请求
- **缓存机制**：重复内容使用缓存结果
- **分批处理**：大文件分段处理
