## ✨ 核心功能概览

**AI Assistant Suite** 是一个强大的Obsidian插件，提供四大核心AI处理模块，帮助你智能化管理和优化笔记内容。

### 🎯 四大AI智能处理模块

#### 📝 AI Structurizer (结构优化器)
- **智能重排与格式化**：优化笔记的逻辑结构和可读性
- **保留原始措辞**：不重写内容，只重新组织和格式化
- **链接保护**：完美处理Obsidian链接和嵌入内容
- **Markdown增强**：自动添加标题、列表、粗体等格式

#### 🏷️ AI Tagger (智能标签)
- **层级标签系统**：生成符合你现有标签体系的层级标签
- **智能翻译**：自动翻译长英文标签为中文
- **上下文感知**：基于笔记内容智能推荐相关标签
- **批量标签管理**：支持选择性添加多个标签

#### 📁 AI Mover (智能移动)
- **文件夹智能推荐**：基于内容分析推荐最佳存放位置
- **自动创建文件夹**：可以创建新的文件夹结构
- **现有结构感知**：优先使用现有文件夹，保持组织一致性
- **多选项建议**：提供多个移动选项供选择

#### 📋 AI Meta (元数据生成)
- **智能标题生成**：创建简洁有力的文件标题
- **自动摘要**：生成2-3句话的内容摘要
- **一句话总结**：提供25字以内的核心要点
- **文件重命名**：可选择是否根据生成的标题重命名文件

### 🚀 一键智能处理
- **组合式处理**：一次性执行多个AI模块
- **可配置流程**：自由选择启用的处理步骤
- **智能优化顺序**：先结构优化，再进行其他处理
- **快捷键支持**：`Cmd/Ctrl + Shift + A` 快速启动

### 📦 批量处理系统
- **文件批量处理**：选择多个文件进行批量AI处理
- **文件夹批量处理**：对整个文件夹进行批量处理
- **进度监控**：实时显示处理进度和状态
- **中断恢复**：支持随时中断和恢复处理

### ⚡ 快速操作系统
- **右键菜单集成**：选中文本后右键快速处理
- **四大快速操作**：
  - 📝 总结 (Ctrl+1) - 对选中内容进行简洁总结
  - ✨ 优化 (Ctrl+2) - 优化文本表达方式
  - 🌐 翻译 (Ctrl+3) - 中英文互译
  - 💡 解释 (Ctrl+4) - 详细解释内容含义
- **结果管理**：支持复制结果或直接插入编辑器

### 🎨 智能用户界面
- **AI助手面板**：统一的操作和结果展示界面
- **实时状态监控**：显示API状态、模型信息
- **处理历史记录**：查看最近的AI处理历史
- **使用统计**：统计各功能使用频率
- **文件信息展示**：显示当前文件的字数、字符数等信息

## 🛠️ 安装与配置

### 安装方法

#### 方法一：手动安装
1. 下载最新版本的插件文件
2. 解压到 `.obsidian/plugins/ai-assistant-suite/` 目录
3. 在Obsidian设置中启用插件

#### 方法二：BRAT安装
1. 安装BRAT插件
2. 添加仓库地址：`your-repo/ai-assistant-suite`
3. 安装并启用插件

### 基础配置

#### 1. API设置 (必需)
```
API Key: 填入你的AI服务API密钥
API URL: https://your-ai-service.com/v1/chat/completions
主模型: gemini-2.5-pro (高质量处理)
辅助模型: gemini-2.5-flash (快速操作)
```

#### 2. 功能配置
- **一键处理配置**：选择启用的AI模块
- **标签设置**：配置标签翻译和生成数量
- **文件夹设置**：设置忽略的文件夹
- **元数据设置**：配置文件名长度限制

## 🎮 使用指南

### 基本使用流程

1. **打开AI助手面板**
   - 点击左侧工具栏的锚点图标
   - 或使用快捷键 `Cmd/Ctrl + Alt + A`

2. **选择处理方式**
   - **单模块处理**：点击工具栏对应图标
   - **一键处理**：在助手面板中配置并点击🚀运行
   - **快速操作**：选中文本后右键选择AI快速操作
   - **批量处理**：在助手面板中选择批量处理

3. **查看和应用结果**
   - 在助手面板中查看AI处理结果
   - 选择性应用建议的修改
   - 复制结果或直接插入编辑器

### 工具栏图标说明
- 🧠 **结构优化**：`brain-circuit` 图标
- 📁 **智能移动**：`folder-input` 图标
- 🏷️ **智能标签**：`tags` 图标
- 📋 **元数据生成**：`file-signature` 图标

## 📋 工作流示例

### 新笔记完整处理流程
1. **创建笔记** → 写入初始内容
2. **结构优化** → 使用AI Structurizer整理格式
3. **生成元数据** → 使用AI Meta生成标题和摘要
4. **添加标签** → 使用AI Tagger添加相关标签
5. **文件归档** → 使用AI Mover移动到合适位置

### 文献笔记处理流程
1. **粘贴原始内容** → 从PDF或网页复制内容
2. **快速总结** → 选中关键段落使用Ctrl+1总结
3. **结构优化** → 整理成清晰的笔记结构
4. **添加个人思考** → 在相关位置添加评论
5. **标签分类** → 添加学科和主题标签

### 批量整理工作流
1. **选择范围** → 选择需要整理的文件夹
2. **备份数据** → 确保重要内容已备份
3. **批量处理** → 启动批量AI处理
4. **结果检查** → 逐一检查处理结果
5. **手动调整** → 对不满意的结果进行微调

## 🔧 故障排除

### 常见问题

**Q: API请求失败怎么办？**
A: 检查API Key和URL配置，确认网络连接正常，查看API服务状态。

**Q: 处理结果不理想？**
A: 可以在设置中自定义提示词，或者调整模型参数。

**Q: 批量处理中断了？**
A: 插件支持中断恢复，可以重新启动批量处理。

**Q: 标签翻译不准确？**
A: 可以在设置中调整翻译提示词或禁用自动翻译。

### 性能优化建议
- **模型选择**：快速操作使用轻量级模型
- **并发控制**：避免同时进行多个AI请求
- **缓存机制**：重复内容使用缓存结果
- **分批处理**：大文件分段处理
